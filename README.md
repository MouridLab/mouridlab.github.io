# MouridLab website

Site public de présentation de [MouridLab](https://github.com/MouridLab), publié avec GitHub Pages sur <https://mouridlab.github.io/>.

Le site est statique et ne collecte aucune donnée personnelle. Toute modification doit préserver l’accessibilité, les métadonnées sociales et la validité des liens vers les projets de l’organisation.

## Vérification locale

```bash
python3 -m http.server 8000
```

Ouvrez ensuite <http://127.0.0.1:8000/>.
